# Web Studio

**Современный адаптивный сайт веб-студии.**

Этот проект представляет собой одностраничный сайт, разработанный для демонстрации услуг в области веб-разработки и дизайна. Код написан с акцентом на скорость, удобство использования и качественный пользовательский опыт на любых устройствах.

## 🚀 О проекте

**Web Studio** — это визитная карточка компании, созданная с использованием современных веб-технологий. Проект включает в себя несколько вспомогательных страниц для демонстрации портфолио, цен и контактной информации.

## ✨ Возможности

*   📱 **Адаптивный дизайн** — корректное отображение на всех устройствах: от мобильных телефонов до настольных компьютеров.
*   ⚡ **Высокая скорость загрузки** — оптимизированный код и ресурсы.
*   🎨 **Современный пользовательский интерфейс** — чистый и интуитивно понятный дизайн.
*   🖥️ **Кроссбраузерная совместимость** — стабильная работа в основных браузерах.
*   ♿ **Доступность (Accessibility)** — базовые принципы для удобства пользователей с ограниченными возможностями.
*   🔍 **SEO-оптимизация** — семантическая верстка для лучшего индексирования поисковыми системами.
*   📩 **Контактная форма** — форма для связи с клиентами.

## 🛠️ Используемые технологии

*   **HTML5** — семантическая структура страниц.
*   **CSS3** — стилизация, анимации, Flexbox и CSS Grid для построения сеток.
*   **JavaScript (ES6+)** — интерактивные элементы и логика.

## 📸 Основные разделы сайта

*   **Главная** — общая информация о студии.
*   **О нас** — краткая информация о команде и подходе.
*   **Услуги** — перечень предлагаемых услуг.
*   **Наши работы** — портфолио с примерами проектов.
*   **Команда** — фотографии и должности сотрудников.
*   **Клиенты** — логотипы партнеров или отзывы.
*   **Контакты** — контактная информация и форма обратной связи.
