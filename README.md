# 🌐 Web Studio

Современный адаптивный сайт-портфолио веб-разработчика, созданный с использованием **HTML5**, **CSS3** и **JavaScript**. Проект демонстрирует навыки разработки современных пользовательских интерфейсов, адаптивной верстки и организации структуры сайта.

## 🚀 Демо

🔗 https://mrmoish.github.io/web-studio/

> *(Если GitHub Pages еще не настроен, ссылку можно заменить после публикации.)*

## ✨ Возможности

- 📱 Полностью адаптивный дизайн
- ⚡ Быстрая загрузка страниц

- 🖼️ Портфолио проектов

## 💻 Локальный запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/mrMoish/web-studio.git
Перейдите в папку проекта:
cd web-studio
Откройте файл:
index.html
или запустите локальный сервер.
Например:
python3 -m http.server
После этого откройте:
http://localhost:8000
