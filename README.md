# Web Studio

Современный адаптивный сайт веб-разработки с акцентом на скорость, удобство использования и качественный пользовательский опыт.

## 🚀 О проекте

Web Studio — это одностраничный сайт, демонстрирующий услуги по разработке современных веб-сайтов и веб-приложений.

Проект создан с использованием современных технологий и адаптирован под любые устройства.

## ✨ Возможности

- 📱 Полностью адаптивный дизайн
- ⚡ Высокая скорость загрузки
- 🎨 Современный пользовательский интерфейс
- 🖥️ Кроссбраузерная совместимость
- ♿ Доступность (Accessibility)
- 🔍 SEO-оптимизация
- 📩 Контактная форма
- 🎯 Чистая структура проекта

## 🛠️ Используемые технологии

- HTML5
- CSS3
- JavaScript (ES6+)

Дополнительно:

- Flexbox

- Responsive Design
- BEM (если используется)

## 🚀 Запуск проекта

### Клонировать репозиторий

```bash
git clone https://github.com/mrMoish/web-studio.git
```

### Перейти в папку проекта

```bash
cd web-studio
```

### Запустить

Достаточно открыть файл `index.html` в браузере.

Или использовать Live Server в VS Code.
